# Logótipo institucional

`protege-logo.jpg` é a versão institucional com o mesmo símbolo, nome e lema apresentados pelo utilizador, obtida em 17/11/2026 através de leitura do website público da PROTEGE:

https://protege.org.mz/wp-content/uploads/2025/12/cropped-Associacao-PROTEGE-Logotipo-scaled-1-e1764770188286.jpg

O ficheiro foi copiado sem edição gráfica. É servido localmente, sem dependência de hotlink e sem modificação do WordPress.

As cores de interface foram aproximadas às cores do logótipo: primária `#48499b`, verde `#159c4b`, laranja `#f5742d`, amarelo `#f8d43b`, azul claro `#60c6e6`, rosa `#cf8bbf`. Variações mais escuras são usadas para legibilidade. A estrutura e os componentes existentes foram mantidos.
